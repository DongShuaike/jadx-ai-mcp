# Changelog

All notable changes to JADX-AI-MCP will be documented here.

## [5.0.0] - 2025-01-01

### Added
- Complete architectural refactoring
- Modular codebase structure
- Comprehensive documentation
- ReadTheDocs integration

### Changed
- Improved error handling
- Enhanced pagination support
- Better type hints in Python code

### Fixed
- Connection stability issues
- Memory leaks in large APKs
- Windows path handling

## [4.0.0] - 2024-12-15

### Added
- Debug tools (stack frames, threads, variables)
- Cross-reference analysis tools
- Refactoring tools

### Changed
- Updated to FastMCP latest version
- Improved MCP protocol compatibility

## [3.0.0] - 2024-11-01

### Added
- Resource analysis tools
- Search tools with pagination
- Main application class detection

## [2.0.0] - 2024-10-01

### Added
- Initial MCP server implementation
- Basic class analysis tools

## [1.0.0] - 2024-09-01

### Added
- Initial JADX plugin release
- HTTP server integration
- Basic API endpoints
